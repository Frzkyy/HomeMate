# HomeMate

> Kelola Rumah, Hidup Lebih Teratur.

Aplikasi desktop Java (Swing) untuk mencatat urusan rumah tangga: anggota keluarga, tugas, persediaan, keuangan, dan perawatan rumah. Tugas kuliah Java, CRUD sederhana.

## Cara menjalankan
1. Buka folder `HomeMate/` (yang ada `nbproject/`) di NetBeans.
2. Pastikan jar `sqlite-jdbc` ada di folder `lib/` dan sudah ditambahkan di Properties, Libraries, Classpath.
3. Klik kanan project, **Run**.

## Dokumentasi
- `docs/PROJECT.md`: struktur folder, pembagian tugas, daftar fitur, tabel database. **Baca ini dulu.**
- `docs/PRD.md`: dokumen kebutuhan asli (referensi, tidak perlu diikuti 100%).
