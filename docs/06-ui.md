# 06 - UI & Navigation

Layout: sidebar biru tua di kiri + area konten di kanan. Tema terang sebagai default, opsi gelap. Teks UI dalam bahasa Indonesia.

## Sidebar
Dashboard, Anggota Keluarga, Tugas Rumah, Persediaan, Keuangan, Perawatan Rumah, Pengingat, Laporan, (bawah) Pengaturan, Keluar.

## Layar

| Layar | Isi utama |
|---|---|
| Login | Username, password (toggle lihat), ingat saya, tombol Masuk, tautan Daftar |
| Dashboard | 4 kartu (Tugas Selesai, Tugas Tertunda, Stok Menipis, Total Pengeluaran), tabel Tugas Hari Ini, panel Stok Menipis |
| Anggota Keluarga | Kartu anggota (nama, peran, tugas selesai) + tabel (No, Nama, Peran, Tugas Selesai, Total Tugas, Aksi) + tombol Tambah Anggota |
| Tugas Rumah | Tab Daftar Tugas / Kalender; tabel (Nama, Penanggung Jawab, Prioritas, Deadline, Status, Aksi); kalender bulanan; panel Detail Tugas + Ubah Status |
| Persediaan | Tabel (Nama, Jumlah, Batas Minimum, Status Menipis/Aman, Aksi); panel Daftar Belanja (checkbox, Tambah ke Daftar); kotak Peringatan |
| Keuangan | Tab Ringkasan / Transaksi / Anggaran / Laporan; kartu Pemasukan, Pengeluaran, Sisa Anggaran; pie chart pengeluaran per kategori; tabel Transaksi Terbaru; filter bulan |
| Perawatan Rumah | Tabel jadwal (Nama, Peralatan/Ruang, Jadwal Berikutnya, Status); tabel Riwayat Perawatan |
| Pengingat | Tab Semua/Tugas/Persediaan/Perawatan/Keuangan; item dengan label kategori dan tanggal |
| Pengaturan | Tab Akun / Aplikasi / Database; info akun, foto profil, tema, toggle notifikasi, tombol Simpan |

Mockup gambar: simpan di `docs/mockup/` (opsional) supaya mudah dirujuk.

## Halaman tambahan
Form tambah/edit data, Detail Tugas, Detail Transaksi, Daftar Belanja, Riwayat Pemeliharaan.

## Warna status (konsisten di semua layar)
| Status | Warna |
|---|---|
| Selesai / Aman / Terjadwal | Hijau |
| Sedang / Sedang Dikerjakan | Kuning-oranye |
| Belum / Menipis / Tinggi | Merah |
| Pemasukan | Hijau, Pengeluaran: Merah |

## Prinsip
- Navigasi konsisten, halaman aktif ditandai di sidebar
- Aksi destruktif (hapus) selalu minta konfirmasi
- Pesan error validasi muncul dekat field yang salah
